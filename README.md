# sprang-brakes
exploring the possibility of dynamic ABS breaks that autonoomously asset the correct course of action to find momentum in wheel rotation against a surface

## use case
tires are sliding from hydroplaning, sprang brakes kick in to find last time there was rotation and interrupt flow of steering, disengaging the actor (driver) from steering until adjustment been applied
